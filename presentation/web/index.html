01 · GENERATIVE AI NOWCASTING

What will the satellite see next?

Every 10 minutes, Meteosat-12 captures a new multispectral view of Europe's evolving atmosphere. But can AI predict what the satellite will observe next?

NVIDIA StormScope-EU is a generative diffusion model that learns the spatiotemporal evolution of satellite imagery across 16 spectral channels.

Starting from six consecutive observations, it generates the next multispectral frame. Each prediction advances a sliding input window, extending the forecast autoregressively through twelve 10-minute steps.

02 · EARTH OBSERVATIONS

Observing Europe's atmosphere from space

The forecast begins approximately 36,000 km above Earth.

EUMETSAT's Meteosat-12 observes Europe and surrounding regions using the Flexible Combined Imager (FCI). Its 16 spectral channels measure reflected solar and emitted thermal radiation, capturing evolving cloud systems, water vapor, and atmospheric structure.

New observations provide updated initial conditions for successive AI forecast cycles.

03 · NVIDIA EARTH2STUDIO

New observations. New forecast cycles.

The atmosphere never stops evolving. Each new set of observations provides an opportunity to initialize an updated forecast.

Using NVIDIA Earth2Studio, the workflow retrieves the latest six available Meteosat frames, prepares the model inputs, and executes StormScope-EU on NVIDIA GPUs.

Each initialization produces twelve successive predictions, extending two hours beyond the forecast reference time. As new observations become available, another forecast cycle can begin.

04 · EARTHMOVER ARRAYLAKE + ICECHUNK

From GPU inference to versioned forecasts

Generating the predictions is only part of the challenge. Large scientific datasets must also move efficiently from GPU compute to cloud storage.

Forecast outputs are transferred to Earthmover Arraylake as inference progresses, overlapping data transfer with subsequent prediction steps to reduce end-to-end publication latency.

Icechunk provides transactional, versioned storage for the resulting multidimensional arrays. Once the forecast is complete, an atomic commit publishes the run as a consistent snapshot.

05 · EARTHMOVER COMPUTE

From scientific data to interactive forecasts

A new forecast has been published. How do we make it accessible without transferring the entire scientific dataset to every user?

Earthmover Compute serves forecasts directly from cloud-native Arraylake datasets, dynamically generating geospatial map tiles and supporting queries against the underlying scientific arrays. The same forecast can power interactive maps, scientific analysis, and downstream applications.
