01 · AI Weather Nowcasting

From Satellite Observations to AI Forecasts

Nowcasting uses recent observations to predict weather over the next minutes to hours.

This demo shows how AI can forecast future satellite imagery over Europe. StormScope-EU is an NVIDIA-trained generative AI model that uses six recent Meteosat-12 observations to predict twelve future satellite frames at 10-minute intervals, extending up to two hours ahead.

Earth2Studio connects satellite data and NVIDIA GPU inference, while Earthmover stores and serves the published forecasts.

02 · Earth Observations

Observing the Atmosphere from Space

Meteosat-12 observes Europe from geostationary orbit, about 36,000 km above Earth.

Its Flexible Combined Imager (FCI) measures reflected solar and emitted infrared radiation across 16 spectral channels. StormScope-EU uses six observations, taken 10 minutes apart, as the starting context for each forecast.

03 · NVIDIA StormScope-EU

Generative Diffusion and Autoregressive Forecasting

StormScope-EU uses generative diffusion to predict the next 16-channel satellite frame from six earlier observations. The model predicts one frame, shifts the six-frame context, and repeats. Predicted frames gradually replace the original observations over twelve steps, reaching +120 minutes.

04 · NVIDIA Earth2Studio

New Observations. New Forecasts.

Earth2Studio connects satellite data, input preparation, StormScope-EU inference on NVIDIA GPUs, and forecast output.

Each StormScope-EU run predicts two hours ahead. As newer observations become available, a new six-frame window can start a separate forecast with its own initialization and publication time.

Observations → Initialize → Predict → Publish · Repeat with newer observations
New observation windows enable new initializations; scan cadence and publication cadence are distinct.
05 · Earthmover Arraylake + Icechunk

Compute and Upload Together. Publish Once.

As StormScope-EU generates predictions on NVIDIA GPUs, forecast fields are uploaded to Earthmover Arraylake. GPU inference and data transfer can run at the same time.

Once all writes finish, a single Icechunk commit atomically publishes the complete two-hour forecast as a consistent, versioned snapshot. Earlier snapshots remain available for comparison.
